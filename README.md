# Skins and Heroes Database

This repository contains **my custom game database** designed for Android applications.

It displays **Skins, Heroes, and Preparations** using **GridView and ListView**, with **online images hosted on GitHub** for easy access and fast loading.

## Project Content
- Skins Database  
- Heroes Database  
- Preparations / Builds  

## Features
- GridView for visual browsing of skins and heroes  
- ListView for detailed information display  
- Online image loading via GitHub hosting  
- JSON-based structured data  
- Optimized for Android and Sketchware projects  

## Technologies Used
- Java (Android)
- GridView & ListView
- JSON
- GitHub (Online Image Hosting)

## Purpose
This project is created as a **game-style database source** that can be used for:
- Game companion apps  
- Skin and hero collections  
- Reference tools for builds and preparations  
- Android apps requiring online assets and organized data  

## Notes
- All images are stored and loaded online from GitHub  
- The database can be extended or customized for other game projects  
- Suitable for beginner to intermediate Android developers
